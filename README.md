# 류경기체

류경기 중랑구청장 명의의 인사말씀, 축사, 축전, 영상 인사 원고, 개조식 말씀자료 초안을 쓰는 Claude 스킬이다. 2026년 8~10월 말씀자료 37편의 문체 분석을 담았다. 말씀 원문과 개인정보는 싣지 않았다.

## 설치

1. 이 저장소의 `skills/ryugyeonggi-che` 폴더를 내려받는다. 저장소 첫 화면의 초록색 `Code` 버튼 → `Download ZIP`으로 전체를 받은 뒤 압축을 푼다.
2. `ryugyeonggi-che` 폴더 하나만 ZIP으로 다시 압축한다. 폴더를 우클릭해 "ZIP 파일로 압축"을 누른다.
3. Claude 앱의 설정 → 사용자 지정 → Skills → 추가 → 스킬 업로드에서 그 ZIP을 올린다.

## 쓰는 법

새 대화에서 행사 내용과 함께 요청한다.

```
구청장님 인사말씀 써 줘.
- 행사: (행사명, 일시, 장소)
- 대상: (누구에게, 몇 명)
- 감사드릴 분: (성함, 직함, 이력)
- 내용: (행사 경과, 관련 수치, 전할 말)
- 형식: 말씀자료 / 영상 원고 / 축전 중 하나
```

## 유의사항

- 결과물은 부서 초안이다. 검토·보완, 부서 최종 확인, 비서실을 거쳐 사용한다.
- 이름과 수치는 입력한 것만 쓴다. `[확인 필요]`, `(보완 바람)` 표시는 반드시 채운다.
- 중랑구 업무용이다. 선거, 정당 관련 글과 구청 업무와 무관한 글에는 쓰지 않는다.
